⓪ Firebase 연결

선생님마다 자기 Firebase(무료)를 연결해서 써요. 처음 한 번만 연결하면 이 브라우저에 저장돼요. 연결하지 않으면 체험 모드로만 돌아가요.

방 만드는 계정: 익명
Firebase 만들고 연결하는 방법 (처음 한 번, 10분쯤)
  1. console.firebase.google.com에 구글 계정으로 들어가 프로젝트 만들기 (애널리틱스는 꺼도 돼요).
  2. 왼쪽 메뉴 빌드 → Authentication → 시작하기 → 로그인 방법 → '익명'을 사용 설정.
  3. 빌드 → Firestore Database → 데이터베이스 만들기 (위치: asia-northeast3 (서울), 프로덕션 모드).
  4. Firestore의 규칙 탭 내용을 모두 지우고 아래 내용을 붙여 넣은 뒤 게시. 
    rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    match /rooms/{code} {
      function isHost() { return request.auth != null &&
        get(/databases/$(db)/documents/rooms/$(code)).data.hostUid == request.auth.uid; }
      function myPid() { return get(/databases/$(db)/documents/rooms/$(code)/sessions/$(request.auth.uid)).data.pid; }
      function taken(pid) { return /databases/$(db)/documents/rooms/$(code)/taken/$(pid); }

      allow read: if request.auth != null;
      allow create: if request.auth != null && request.resource.data.hostUid == request.auth.uid;
      allow update, delete: if request.auth != null && resource.data.hostUid == request.auth.uid;

      match /keys/{kid} {
        allow create: if request.auth != null
          && kid.split('_')[0] == request.resource.data.pid
          && (!exists(taken(request.resource.data.pid)) || get(taken(request.resource.data.pid)).data.reset == true);
        allow read, delete: if isHost();
      }
      match /sessions/{uid} {
        allow read: if request.auth != null && request.auth.uid == uid;
        allow create, update: if request.auth != null && request.auth.uid == uid
          && exists(/databases/$(db)/documents/rooms/$(code)/keys/$(request.resource.data.pid + '_' + request.resource.data.k));
      }
      match /taken/{pid} {
        allow get: if request.auth != null;
        allow create, update: if isHost() || (request.auth != null && myPid() == pid);
      }
      match /players/{pid} {
        allow read: if isHost() || (request.auth != null && resource.data.uid == request.auth.uid);
        allow create, update: if isHost() || (request.auth != null && myPid() == pid
          && request.resource.data.uid == request.auth.uid);
      }
      match /comments/{pid} {
        allow read: if isHost();
        allow create: if request.auth != null && request.resource.data.uid == request.auth.uid
          && request.resource.data.text is string && request.resource.data.text.size() <= 60;
      }
      match /answers/{aid} {
        allow read: if isHost();
        allow create: if request.auth != null && request.resource.data.uid == request.auth.uid;
      }
    }
  }
}
  5. 프로젝트 설정(톱니바퀴) → 내 앱 → 웹(</>) 앱 추가 → 앱 이름만 적고 등록 → 나오는 firebaseConfig 코드를 통째로 복사해 아래 칸에 붙여 넣고 연결하기.

무료(Spark) 한도는 하루 읽기 5만·쓰기 2만 건이에요. 400명 규모 행사 한 번은 대체로 들어오지만, 리허설은 행사 전날 해 주세요(한도는 매일 오후 5시쯤 초기화). 불안하면 Blaze(종량제)로 바꾸고 예산 알림을 걸어 두세요.
